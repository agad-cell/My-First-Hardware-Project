## Description
This is a home automation project and its code is written using blocks the LED turns on when the light level is less than 500 and it turns off when the light level is greater than 500 this means it turns on in darkness and turns off in daylight or sunlight it is inspired by real-life home automation systems these systems are made to reduce the waste of electricity because people often forget to turn off lights and this helps reduce electricity costs.

## How to Use It
Connect the Arduino to the LDR (light sensor) and LED using a breadboard
Upload or run the mBlock code on the Arduino
Place the LDR in an area where it can detect light changes
When the environment becomes dark, the LED/light turns ON automatically
When light is detected again, the LED/light turns OFF
